# Lane Detection Models

This repository contains multiple deep learning models for lane detection and segmentation that I explored and compared as part of my computer vision research.

## Models Included

- **Ultra Fast Lane Detection (UFLD)**
  - Lightweight and real-time lane detection.
  - Used as the primary model for my experiments.

- **CLRNet**
  - Cross Layer Refinement Network for robust lane detection.
  - Explored for improved accuracy on challenging road scenes.

- **CLRerNet**
  - Enhanced implementation based on CLRNet with additional refinements.
  - Evaluated as an alternative to UFLD.

## Purpose

The goal of this repository is to:

- Compare different lane detection approaches.
- Understand their architectures and inference pipelines.
- Evaluate their performance on dashcam videos.
- Integrate lane detection into a complete Advanced Driver Assistance System (ADAS) pipeline.
